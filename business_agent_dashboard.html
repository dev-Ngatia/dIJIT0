ICT Principles for Business

Security by Design
Encrypt data in transit (HTTPS/TLS) and at rest. Use .env files for API keys. Never hardcode secrets. Run agents with least-privilege service accounts.
Scalability
Design agents as stateless microservices. Use queues (Redis, RabbitMQ) to decouple. n8n handles orchestration so Python agents stay lean.
Data Management
Single source of truth — Google Sheets or Supabase. Agents read/write via API. Maintain audit logs for every automated action.
Reliability / Uptime
Use systemd or PM2 to keep Python agents alive. n8n's built-in retry logic handles transient failures. Monitor with UptimeRobot.
Interoperability
REST + JSON as the contract between all components. n8n's 400+ integrations make connecting new tools a config change, not code.

Setup Guide — Python + n8n Localhost

Step 1 — Install & run n8n

1
Install n8n globally
npm install -g n8n
2
Start n8n
n8n start # Open http://localhost:5678

Step 2 — Python Agent Server

# Install dependencies pip install fastapi uvicorn anthropic python-dotenv # .env file ANTHROPIC_API_KEY=sk-ant-... # main.py from fastapi import FastAPI from anthropic import Anthropic from dotenv import load_dotenv import os load_dotenv() app = FastAPI(title="Business Agent API") client = Anthropic(api_key=os.getenv("ANTHROPIC_API_KEY")) @app.post("/agents/{agent_name}") async def run_agent(agent_name: str, body: dict): system_prompts = { "content": "You are an expert content creator for social media...", "seo": "You are an SEO specialist. Analyse and recommend...", "leads": "You are a B2B lead qualification expert...", } result = client.messages.create( model="claude-sonnet-4-20250514", max_tokens=1024, system=system_prompts.get(agent_name, "You are a helpful business agent."), messages=[{"role": "user", "content": body["prompt"]}] ) return {"agent": agent_name, "result": result.content[0].text} # Run: uvicorn main:app --reload --port 8000

Step 3 — Connect n8n → Python Agent

In n8n, add an HTTP Request node with these settings:
FieldValue
MethodPOST
URLhttp://localhost:8000/agents/content
Body TypeJSON
Body{"prompt": "{{ $json.topic }}"}
ResponseJSON → use {{ $json.result }}

Step 4 — Run as a service (PM2)

npm install -g pm2 # Start Python agent pm2 start "uvicorn main:app --port 8000" --name agents # Start n8n pm2 start "n8n start" --name n8n pm2 save && pm2 startup
